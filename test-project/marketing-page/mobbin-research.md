# Linear Marketing Site - Design Research

**Source:** Mobbin.com analysis of linear.app
**Date:** 2026-01-05

## Key Design Patterns

### 1. Hero Section
- **Background:** Pure dark (#0A0A0A or similar) with subtle purple/blue gradient
- **Headline:** Large, bold white text
  - Example: "Linear is a purpose-built tool for planning and building products"
- **Supporting copy:** Muted gray text below headline
  - "Meet the system for modern product development. Streamline issues, projects, and product roadmaps."
- **CTA:** Ghost button style ("Start building") - outlined, not filled
- **Visual:** Product screenshot overlaid on dark background

### 2. Navigation
- Clean horizontal nav: Logo | Product | Method | Customers | Changelog | Pricing | Company | Contact | Log In | Sign up
- Sign up button is highlighted (filled)
- Sticky/fixed position

### 3. Features Section
- **Layout:** Split - left sidebar nav + right content
- **Section label:** Small caps category ("PLAN")
- **Headline:** Action-oriented ("Planning tools that help you ship")
- **Feature list:** Vertical nav with icons (Issues, Cycles, Projects, Initiatives, Teams, Backlog)
- **Sub-features:** Progress, Collaborate, Analyze, Level up, Secure
- **Content:** Feature name + bold descriptor + supporting copy + screenshot

### 4. Integrations Section
- **Background:** Dark
- **Icons:** Row of app logos (Slack, GitHub, Figma, etc.)
- **Label:** "INTEGRATIONS"
- **Headline:** "Dozens of apps. Endless possibilities."
- **Filter tabs:** Collaboration, Automations, Engineering, Bug Reporting, Customer Experience

### 5. CTA Section
- **Background:** Light gradient (white to light gray)
- **Centered layout:** Logo → Headline → CTA
- **Headline:** "Start building products better"
- **CTA button:** Filled purple/dark button ("Try Linear for free")
- **Footer visible below**

## Typography
- **Headings:** Sans-serif (likely Inter or custom)
- **Body:** Clean, readable sans-serif
- **Hierarchy:** Clear size/weight distinction between H1, H2, body

## Color Palette
- **Primary background:** Near-black (#0A0A0A - #1A1A1A)
- **Secondary background:** Light gray gradient
- **Text primary:** White (#FFFFFF)
- **Text secondary:** Muted gray (#888888)
- **Accent:** Purple/violet for CTAs and highlights

## Spacing
- **Hero:** Generous vertical padding (100px+)
- **Sections:** Consistent section padding
- **Grid:** Clean alignment, 12-column implied

## Animation Patterns (observed)
- Subtle gradient motion in backgrounds
- Smooth scroll transitions
- Hover effects on buttons and links

## Key Takeaways for AudienceOS
1. **Dark mode first** - Makes product screenshots pop
2. **One clear CTA per section** - Don't overwhelm
3. **Feature sidebar nav** - Good for multiple features
4. **Social proof through integrations** - Shows ecosystem
5. **Ghost buttons for secondary actions** - Clean aesthetic
6. **Section labels** - Help orient visitors
