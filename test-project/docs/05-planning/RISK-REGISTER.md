# Risk Register: AudienceOS Marketing Page

## Risks

### R1: Design Coherence
- **Risk:** Page doesn't feel "Linear-quality"
- **Likelihood:** Medium
- **Impact:** High
- **Mitigation:** Use Mobbin research, follow Linear patterns exactly

### R2: Performance
- **Risk:** Heavy animations slow page
- **Likelihood:** Low
- **Impact:** Medium
- **Mitigation:** CSS-only animations, no JS libraries

### R3: Mobile Experience
- **Risk:** Desktop-first design breaks on mobile
- **Likelihood:** Medium
- **Impact:** High
- **Mitigation:** Mobile-first Tailwind approach

## Dependencies
- Tailwind CSS
- No external dependencies (pure HTML/CSS)
