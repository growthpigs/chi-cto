# PRD: AudienceOS Marketing Page

## User Stories

### US-1: First Impression
As a visitor, I want to immediately understand what AudienceOS does so I can decide if it's relevant.

**Acceptance Criteria:**
- Hero headline visible above fold
- Value prop clear in < 5 seconds
- CTA prominent

### US-2: Feature Discovery
As a visitor, I want to see key features so I can understand the product benefits.

**Acceptance Criteria:**
- 3 feature cards visible
- Icons communicate function
- Brief descriptions

### US-3: Taking Action
As an interested visitor, I want to sign up easily so I can try the product.

**Acceptance Criteria:**
- Single CTA button
- Form takes < 30s to complete
- Success feedback

## Technical Requirements
- HTML + Tailwind CSS
- No JavaScript dependencies
- < 100KB total page weight
- 95+ Lighthouse score
